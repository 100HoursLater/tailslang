## What is Tails lang 

*tailslang* or just *tails* is a new generation programming language built around OOP principles 

it's a mixed type language capable of using both explicit types (int, float, char etc) and implicit types (var and const) 

it also supports async functions and the language scales to you and your learning. 

You can start off using implicit types and then scale to explicit types and more powerful language features like inheritance, speaking of. 

it also supports class overloading 

### Inheritance 

`extends` - this means the new class inherits everything from the base class, but changes are shared back to the base class
`supersedes` - this means the new class replaces the old class completely (you can still go back to the old class by deleting the superseding class)
`superset` - a superset inherits the values, functions or other classes inside of math while not sharing any changes back to the base class
`subset` - this means the new class will only inherit functions from the base class 

Inheritance in *tails* is designed to be super scalable, and meant to match you where you're at, it's also meant to give you more flexibility
